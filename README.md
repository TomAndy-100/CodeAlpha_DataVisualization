# CodeAlpha_DataVisualization

E-commerce Product Data Analysis

📌 Overview

A beginner-level data analysis project involving the collection, organization, and analysis of product data from a simulated e-commerce website.

The project helped me practice the basic data analysis workflow using Python.

🛠️ Tools Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib
- Excel

🔄 Workflow

Web Scraping → Data Cleaning/Organization → Pandas → Analysis → Visualization → Excel

📊 Analysis

The dataset was explored through:

- Price distribution
- Rating distribution
- Top 10 most expensive products
- Price vs. rating scatter plot
- Price distribution and outlier analysis
- Rating frequency

🔎 Key Findings

- Product ratings were generally concentrated toward the higher end.
- The top 10 most expensive products had relatively similar prices.
- The price vs. rating scatter plot showed no obvious relationship.
- The calculated correlation between price and rating was approximately 0.05, indicating almost no linear relationship in this dataset.

💡 What I Learned

This project helped me understand the flow of a basic data analysis project:

Collect → Organize → Analyze → Visualize → Interpret

It also helped me move from simply seeing Python syntax to understanding how different tools work together in a real data workflow.
